# Tipografía del sitio: Exo 2

Exo 2 variable, pesos 100–900, normal y cursiva, con subconjuntos Latin y Latin Extended. Los archivos se sirven localmente para que las páginas no dependan de una conexión a Google Fonts.

- Licencia: SIL Open Font License 1.1; ver `Exo-2-OFL.txt`.
- Autores: The Exo 2 Project Authors.
- Repositorio oficial: https://github.com/googlefonts/Exo-2.0
- Licencia fuente: https://github.com/google/fonts/blob/main/ofl/exo2/OFL.txt
- Distribución WOFF2 oficial: Google Fonts, versión de URL `v26`, consultada el 2026-11-04.
- CSS fuente: https://fonts.googleapis.com/css2?family=Exo+2:ital,wght@0,100..900;1,100..900&display=swap

El logo usa contornos vectoriales Racing V2 aprobados por el cliente, no Exo 2. Exo 2 es la familia completa complementaria para el texto del sitio: lectura en normal y títulos en cursiva de mayor peso.
